## Installation

To get started with this project, you need to have Power BI Desktop installed on your machine. You can download it from the [official Power BI website](https://powerbi.microsoft.com/desktop/).

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/Adarsh572sg/Sales-data-in-Power-Bi-Work.git
   ```

2. Open the Power BI Desktop application.

3. Open the `.pbix` file from the cloned repository.
